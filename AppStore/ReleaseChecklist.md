# CareNotes — App Store Release Checklist

## Metadata
- [ ] App name and subtitle finalised
- [ ] Categories confirmed
- [ ] Keywords within 100 bytes
- [ ] Promotional text within 170 characters
- [ ] Description matches implemented features
- [ ] Support, marketing and privacy URLs checked
- [ ] Age rating and content rights documented

## Visual Assets
- [ ] 1024x1024 PNG app icon
- [ ] Five promotional screenshots
- [ ] One genuine Dark Mode screenshot
- [ ] Correct screenshot dimensions
- [ ] No private patient information shown

## Application Quality
- [ ] Light Mode tested
- [ ] Dark Mode tested
- [ ] Dynamic Type tested
- [ ] Accessible labels checked
- [ ] Touch targets checked
- [ ] Empty and error states tested
- [ ] Permission denial handled
- [ ] No placeholder content
- [ ] No fatal crashes

## Submission
- [ ] App Store materials included in group PDF
- [ ] App Store assets committed to GitHub
- [ ] Pull request reviewed
- [ ] Team Contribution Matrix updated
- [ ] Individual reflection completed
